# Verdant Jars

A touch-friendly jar-building game for kids. Pick a glass jar, pour soil layers, plant things, invite pets, water the plants, make it rain, earn stars and keep your favorite jars.

## Play

Open `index.html` in any modern browser, or use the GitHub Pages link for this repository.

## Features

- 5 glass jars, 6 soil layers and about 33 plants, rocks, pets and fun things
- Pets that hop, crawl, fly and react when tapped, with sounds
- Watering, rain, rainbow, sunny, sunset and night skies
- 12 missions with stars and confetti
- Autosave, undo, a photo maker and up to 8 kept jars (saved in the browser)

Everything lives in one file with no build step.
